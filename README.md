# 楚汉棋社

可通过邀请链接进入的中国象棋好友对战网页。无需注册，匿名座位身份由 HttpOnly Cookie 保存，棋局存于 D1。两位玩家入座后开始，后续访客以观战身份进入。

## 已实现

- 中国象棋合法走棋、将军、将死、困毙、超时判负。
- 任意一方无限撤回最近一步，无需另一方确认；恢复棋子、吃子、轮次和该步开始时的用时。终局后仍可悔棋。
- 提和、认输、双方同意重新开局并交换红黑。
- 不限时或每方 10 / 20 / 30 分钟，服务器裁决时钟。
- 逐步棋谱、历史回看、从任意局面独立推演、棋谱文本导出。
- 翻转棋盘、合法落点提示、落子音效、聊天、称呼修改、在线状态、刷新恢复。
- 定期同步和服务器版本比较，避免并发操作覆盖。
- 三次重复局面时：单方持续将军者判负，否则判和；60 回合未吃子判和。

复杂长捉等完整赛事裁判细则不在当前好友局裁决范围内，页面规则中有明确说明。当前版本不包含人机对战、排位或付费模块。

## 开发与验证

使用 `npm install` 安装依赖，`npm run dev` 开发，`npm run build` 构建。

数据库定义在 `db/schema.ts`，使用 `npm run db:generate` 生成迁移。生产迁移由 Sites 发布流程应用。本地数据库需使用 Wrangler 将 `drizzle/*.sql` 应用到本机 D1，数据路径 `.wrangler/state`。

- `npm test`：棋规与对局状态测试，包含标准开局三层走法总数 44 / 1920 / 79666。
- `npm run test:online -- http://localhost:3000`：通过两个独立身份及观战者验证 API 对局流程。
- `npx tsc --noEmit`：类型检查。

棋局没有公开列表；持有棋室链接者可以进入或观战。保留原浏览器数据可恢复座位。重开前可导出棋谱；重开会替换当前棋谱。
